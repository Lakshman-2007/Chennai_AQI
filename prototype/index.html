How a run works

01
Authenticate
Browser or headless OAuth flow against a Google Cloud project with Earth Engine enabled.
02
Collect
Pull COPERNICUS/S5P/OFFL/L3_NO2 over the Chennai box for each day in range.
03
Filter
Drop pixels below qa_value 0.75, then spatially average what's left.
04
Validate
Check for duplicate dates, outliers, NaN/Inf. A failure blocks export entirely.
05
Export
Write the CSV plus a metadata JSON documenting exactly how it was produced.

Run configuration

# config/chennai.yaml
region: Chennai, bbox 12.83–13.27°N · 80.03–80.34°E
date: 2025-01-01 → 2025-01-31
variable: NO2 (tropospheric_NO2_column_number_density, mol/m²)
aggregation: mean, daily
quality: enabled, qa_value > 0.75
output: sentinel5p_chennai.csv + metadata JSON
